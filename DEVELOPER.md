# Руководство разработчика Torrent Media Sorter Web v0.1 👨‍💻

Этот документ описывает внутреннюю архитектуру проекта, используемые технологии и принципы взаимодействия компонентов.

---

## 🏗 Архитектура проекта

Проект построен на базе **FastAPI** (бэкенд) и **HTMX** (фронтенд-взаимодействие), что позволяет создавать динамический интерфейс без использования тяжелых JS-фреймворков.

### Структура папок:
- `app/api/`: Обработчики вебхуков и внешних API запросов.
- `app/core/`: Ядро системы (бизнес-логика):
    - `processor.py`: Главный дирижер процесса обработки.
    - `metadata.py`: Логика работы с внешними API (KP, TMDB, TVDB).
    - `scanner.py`: Алгоритм первичного распознавания имен файлов.
    - `operations.py`: Файловые операции (перенос, хардлинки).
- `app/web/`: Веб-интерфейс:
    - `routes.py`: Маршруты для страниц и HTMX-запросов.
    - `templates/`: Jinja2 шаблоны.
- `data/`: Локальное хранилище (БД SQLite, логи, конфигурация).

## 🔄 Механика HTMX и живых обновлений

Одной из ключевых особенностей версии 0.1 является использование **OOB (Out-of-Band) Swaps** для обновления статусов в таблице.

### Как работает живое обновление:
1. В `layout.html` определен глобальный контейнер `#modal-placeholder`.
2. В `dashboard.html` запущен скрытый воркер:
   ```html
   <div hx-get="/api/status-updates" hx-trigger="every 10s" hx-swap="none"></div>
   ```
3. Сервер на эндпоинт `/api/status-updates` возвращает список строк `<tr>`, каждая из которых помечена атрибутом `hx-swap-oob="true"`.
4. HTMX автоматически заменяет строки в таблице по их `id="row-{{id}}"`, не затрагивая остальную страницу и открытые модальные окна.

### Модальные окна:
- Модальные окна загружаются динамически в `#modal-placeholder`.
- Для корректной работы при переключении между окнами используется событие `htmx:afterSettle` с микро-задержкой для инициализации стилей Tailwind и блокировки прокрутки фона (`body.modal-open`).

## 🗄 База данных (SQLAlchemy)

Используется **SQLite** с асинхронным драйвером. Ключевые таблицы:
- `downloads`: Информация о торрентах, их статусах, типах медиа и логах обработки.
- `file_moves`: История перемещения конкретных файлов (используется для функции **Undo**).
- `system_logs`: Системный журнал действий.
- `users`: Данные авторизации.

## 🛠 Разработка и запуск

1. **Окружение**:
   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

2. **Запуск в режиме отладки**:
   ```bash
   uvicorn app.main:app --reload --port 7887
   ```

3. **Конфигурация**:
   Все настройки хранятся в `data/config.ini`. При первом запуске система создает конфигурацию по умолчанию.

## 🛡 Безопасность
- Пароли хранятся в виде хешей `sha256_crypt`.
- Сессии защищены с помощью `itsdangerous`.
- Все формы защищены от повторной отправки и конфликтов в DOM благодаря статичному размещению контейнеров.
