Инструкция по получению API ключей

Следуйте шагам для настройки интеграций

KP

Кинопоиск (Unofficial)

  1. Зарегистрируйтесь на сайте kinopoiskapiunofficial.tech
  2. Перейдите в личный кабинет (профиль).
  3. Скопируйте ваш персональный API Key.
  4. Вставьте его в поле Kinopoisk в настройках Sorter.
TM

The Movie Database (TMDB)

  1. Зайдите на themoviedb.org и войдите в аккаунт.
  2. Перейдите в Настройки -> API.
  3. Нажмите "Создать" (Create) и выберите тип "Developer".
  4. Заполните анкету (можно указать "Personal use").
  5. После одобрения скопируйте API Key (v3 auth).
TV

TheTVDB

  1. Зарегистрируйтесь на thetvdb.com.
  2. Перейдите в Dashboard -> API Keys.
  3. Создайте новый проект (Project Name: TorrentSorter).
  4. Скопируйте API Key.
IG

IGDB (Games via Twitch)

  1. Авторизуйтесь в Twitch Developer Console.
  2. Нажмите "Register Your Application".
  3. Имя: любое (напр. Sorter), OAuth Redirect URL: http://localhost, Category: "Application Integration".
  4. После создания вы увидите Client ID.
  5. Нажмите "New Secret", чтобы получить Client Secret. (Внимание: он показывается один раз!)
TG

Telegram Bot

  1. Напишите боту @BotFather в Telegram.
  2. Отправьте команду /newbot и следуйте инструкциям для создания бота.
  3. Скопируйте полученный HTTP API Token.
  4. Чтобы узнать свой Chat ID, напишите боту @userinfobot.
