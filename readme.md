# Torrent Media Sorter (Web Service) 📦🎬

Интеллектуальный помощник для автоматической сортировки, переименования и управления медиатекой. Сервис принимает уведомления от торрент-клиентов (Transmission, qBittorrent) по завершении закачки, находит метаданные в популярных базах (Кинопоиск, TMDB, TVDB) и раскладывает файлы по папкам.

---

## 🚀 Основные возможности

- **Автоматизация 24/7**: Работает как фоновый сервис, полностью заменяя ручную сортировку.
- **Безопасность и роли**: Встроенная система авторизации (логин/пароль) для защиты веб-интерфейса.
- **Визуальный конструктор имен**: Настраивайте шаблон имени файла простым перетаскиванием блоков (Название, Год, Тег серии, Имя торрента и др.).
- **Каскадный поиск метаданных**: Если фильм не найден в одном источнике, система автоматически опрашивает следующий (KP -> TMDB -> TVDB).
- **Режимы обработки файлов**:
  - **Move (Перемещение)**: Переносит файл в медиатеку, удаляя оригинал.
  - **Copy (Копирование)**: Копирует файл, оставляя оригинал на месте.
  - **Hardlink (Жесткая ссылка)**: Создает "ссылку" на файл в медиатеке мгновенно и без затрат места на диске. Оригинал остается на раздаче (рекомендуется для торрентов).
- **Интуитивный Dashboard**: Управление очередью, возможность отката операций (Undo), исправления сопоставления (Fix Match) или повторной обработки (Retry).
- **Продвинутое логирование**: 4 уровня детализации (от "Только ошибки" до "Полный дебаг") с автоматической очисткой старых записей.

## 🛠 Установка (Linux)

Рекомендуется устанавливать приложение в каталог `/opt/torrent-media-sorter-web`.

### 1. Автоматическая установка через Docker (Рекомендуется)
```bash
mkdir -p /opt/torrent-media-sorter-web && cd /opt/torrent-media-sorter-web
curl -sSL https://raw.githubusercontent.com/kornalexandr2/Torrent-Media-Sorter-Web/main/install_docker.sh | bash
```

### 2. Запуск через Docker Compose
```bash
docker-compose up -d --build
```

## ⚙️ Логика работы

### 1. Получение уведомления
Сервис ожидает POST-запрос на `/api/webhook`. Его отправляет торрент-клиент через скрипт `process_torrent.py` при завершении закачки.

### 2. Распознавание контента (Scanner)
Алгоритм анализирует имя торрента:
- Очищает его от "мусора" (1080p, BluRay, HEVC, и т.д.).
- Ищет метки сезона/серии (S01E01, 1x05).
- Если найдены метки серии — контент помечается как **Сериал**, иначе — как **Фильм**.

### 3. Поиск метаданных (Metadata)
Система ищет информацию по очищенному названию в базах данных. Используется каскад: если Кинопоиск ничего не вернул, запрос идет в TMDB и далее в TVDB. Вы получаете: правильное название на выбранном языке, оригинальное название и год выпуска.

### 4. Сортировка по папкам (Processor)
Файлы распределяются согласно настройкам путей:
- **Фильмы**: `/Movies/Название (Год)/Файл.mkv`
- **Сериалы**: `/Series/Название (Год)/Season 01/Файл.mkv` (подпапки сезонов настраиваются).
- **Прочее**: Если тип не определен, файлы уходят в `other_folder`.

### 5. Переименование файла (Renamer)
Имя файла формируется на основе вашего шаблона из конструктора. 
- *Пример шаблона:* `[name_lang] ([year]) - [torrent] [tag]`
- *Результат:* `Начало (2010) - Inception.2010.1080p.mkv`

## 📑 Описание настроек (Tabs)

1. **Основные**:
   - Пути к папкам медиатеки.
   - Режим работы (Move/Copy/Hardlink).
   - **Конструктор имени файла**: Визуальный редактор шаблона.
2. **API & Маски**:
   - Ключи API для Kinopoisk, TMDB, TVDB.
   - Приоритет поиска (какой сервис опрашивать первым).
   - Пользовательские Regex-маски для тонкой настройки сканера.
3. **Уведомления**:
   - Настройка Telegram-бота (Token, Chat ID) и шаблона сообщения.
4. **Клиент**:
   - Параметры подключения к вашему торрент-клиенту для автоматического удаления торрента после успешной обработки.
5. **Система**:
   - **Уровень логирования**: 0 (Выкл), 1 (Операции), 2 (Ошибки), 3 (Дебаг).
   - **Срок хранения логов**: Время в часах, после которого старые логи удаляются.
   - **Безопасность**: Смена пароля администратора.
