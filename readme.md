# Torrent Media Sorter (Web) v0.1 📦🎬

**Torrent Media Sorter** — это интеллектуальный веб-сервис для автоматизации процесса организации вашей медиатеки. Если вы устали вручную переименовывать файлы и раскладывать их по папкам после завершения закачки в торрент-клиенте, этот инструмент возьмет всю рутину на себя.

Система интегрируется с торрент-клиентом, получает уведомление о завершении загрузки, определяет тип контента, находит метаданные в мировых базах данных и перемещает файлы в структуру вашей медиатеки, сохраняя порядок и правильное именование.

---

## ✨ Основные возможности v0.1

*   **Автоматическое распознавание**: Система анализирует имя торрента для автоматического определения **Фильмов и Сериалов**. Поддержка других категорий (Игры, ПО) находится в планах.
*   **Умный поиск метаданных**: Каскадный опрос баз **Кинопоиск**, **TMDB** и **TVDB** (для видеоконтента). Если информации нет в одном источнике, сервис автоматически проверит следующий.
*   **Живой интерфейс (Dashboard)**: Современная панель управления на базе технологии HTMX. Статусы обновляются "на лету" без перезагрузки всей страницы.
*   **Мультиязычность**: Полная поддержка русского и английского языков. Переключайте язык интерфейса "в один клик", при этом системные логи и история обработки также адаптируются под выбранный язык.
*   **Визуальный конструктор имен**: Настраивайте формат имен файлов (например, `Название (Год) [Тег серии]`) прямо в настройках простым перетаскиванием блоков.
*   **Гибкие режимы обработки**:
    *   **Hardlink (Жесткая ссылка)**: Рекомендуемый режим. Файл мгновенно появляется в медиатеке, не занимая дополнительного места на диске, при этом оригинал остается в папке загрузок для продолжения раздачи.
    *   **Move/Copy**: Классическое перемещение или копирование файлов.
*   **Гибкая сортировка**: Нативная поддержка видеоконтента. Игры и Программное обеспечение могут быть классифицированы вручную через функцию **Fix Match**.
*   **Ручной контроль**: Если автоматика не справилась, функция **Fix Match** позволит вам вручную указать правильный ID фильма или тип контента.
*   **Telegram-уведомления**: Получайте отчеты об успешно обработанных новинках прямо в мессенджер.

## 🛠 Установка и запуск

Приложение может быть развернуто тремя способами в зависимости от ваших предпочтений и инфраструктуры.

### Способ 1: Docker (Самый быстрый запуск)
Этот способ идеально подходит для быстрого ознакомления. Все зависимости уже упакованы в образ.

```bash
docker run -d \
  --name media_sorter \
  -p 7887:8080 \
  -v /opt/torrent-media-sorter/config:/app/config \
  -v /mnt/media:/mnt/media \
  -e TZ=Europe/Moscow \
  kornalexandr2/torrent-media-sorter-web:latest
```
**Комментарии к команде:**
*   `-p 7887:8080`: проброс порта. Интерфейс будет доступен на порту `7887`.
*   `-v .../config`: папка, где будет храниться база данных SQLite и ваш файл настроек.
*   `-v /mnt/media`: путь к вашему хранилищу (должен быть доступен и торрент-клиенту, и сортеру).

### Способ 2: Docker-Compose (Рекомендуется для постоянной работы)
Использование compose-файла позволяет легко управлять путями и обновлять сервис.

**Пример `docker-compose.yml`:**
```yaml
services:
  media-sorter:
    image: kornalexandr2/torrent-media-sorter-web:latest
    container_name: media_sorter
    restart: unless-stopped
    ports:
      - "7887:8080" # Порт в браузере : Порт внутри контейнера
    volumes:
      - ./config:/app/config  # Настройки приложения и БД
      - /mnt/media:/mnt/media # Путь к файлам медиатеки и загрузкам
    environment:
      - TZ=Europe/Moscow      # Часовой пояс для корректных логов
      - PUID=1000             # ID пользователя (для прав на файлы)
      - PGID=1000             # ID группы
```
**Запуск:** Выполните `docker-compose up -d` в папке с файлом.

### Способ 3: В качестве системной службы (Linux / Systemd)
Подходит для установки напрямую на "железо" или виртуальную машину (Ubuntu, Debian).

```bash
mkdir -p /opt/torrent-media-sorter-web && cd /opt/torrent-media-sorter-web
curl -sSL https://raw.githubusercontent.com/kornalexandr2/Torrent-Media-Sorter-Web/main/install_service.sh | bash
```
**Что сделает скрипт:**
1.  Установит необходимые системные пакеты (Git, Python venv).
2.  Создаст изолированное виртуальное окружение.
3.  Настроит автоматический запуск приложения при загрузке системы через `systemctl`.
4.  Проверит доступность выбранного порта.

## ⚙️ Логика и процессы

### Процесс обработки
Когда торрент-клиент сообщает о завершении загрузки (через скрипт-обработчик):
1.  **Scanner**: Очищает название от тегов качества (1080p, HDR) и ищет признаки сезона/серии.
2.  **Metadata**: Опрашивает API для получения официального названия, года и обложки.
3.  **Processor**: Проверяет наличие свободного места и выполняет Hardlink или Move в соответствующую папку (Movies, Series, Games).
4.  **Renamer**: Применяет выбранный вами шаблон имени (например, заменяет точки на пробелы, добавляет год в скобках).

### Режимы сканирования
Кнопка **🔄 Сканировать** поддерживает два режима:
*   **Полная обработка**: Поиск -> Распознавание -> Перемещение.
*   **Только прочитать папку**: Система просто внесет файлы в список, чтобы вы могли обработать их позже вручную.

### Локализация (I18n)
Файлы перевода хранятся в папке `app/locales/` в формате JSON. Вы можете легко изменить любой текст или добавить новый язык, создав соответствующий файл (например, `de.json`).

## 🗺 Roadmap (Планы по развитию)

Мы постоянно работаем над улучшением сервиса. Вот что планируется реализовать в ближайших версиях:

1.  **Автоматизация для Игр**: Интеграция с базами данных (IGDB/RAWG) для автоматического получения обложек и описаний игровых релизов.
2.  **Категория "Программы"**: Полноценная логика распознавания и сортировки софта по категориям.
3.  **Расширение списка клиентов**: Поддержка популярных торрент-клиентов Deluge и rTorrent.
4.  **Статистика и отчеты**: Визуальные графики на Dashboard (объем медиатеки, динамика обработки файлов).
5.  **Умные фильтры**: Возможность гибкой настройки исключений (по релиз-группам, ключевым словам или качеству).
6.  **Детекция качества**: Автоматическое извлечение разрешения (1080p, 4K), HDR и кодеков из имени файла для включения этих данных в шаблон переименования.
