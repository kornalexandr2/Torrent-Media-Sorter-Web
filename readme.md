# Torrent Media Sorter (Web) v0.1 📦🎬

Интеллектуальный помощник для автоматической сортировки, переименования и управления медиатекой. Сервис принимает уведомления от торрент-клиентов (Transmission, qBittorrent) по завершении закачки, находит метаданные в популярных базах (Кинопоиск, TMDB, TVDB) и организует файлы по категориям (Фильмы, Сериалы, Игры, ПО).

---

## 🚀 Основные возможности v0.1

- **Автоматизация и ручной контроль**: Работает как фоновый сервис, но позволяет запускать ручное сканирование с выбором режима ("Полная обработка" или "Только чтение").
- **Умный Dashboard**: Живое обновление статусов без перезагрузки всей страницы (HTMX OOB Swaps). 
- **Безопасность**: Защищенный вход (логин/пароль) и управление пользователями.
- **Гибкая сортировка**: Поддержка Фильмов, Сериалов, Игр и Программного обеспечения.
- **Режимы обработки**:
  - **Move (Перемещение)**: Перенос в медиатеку с удалением оригинала.
  - **Copy (Копирование)**: Копирование с сохранением оригинала.
  - **Hardlink (Жесткая ссылка)**: Мгновенное создание ссылки. Оригинал остается на раздаче (рекомендуется).
- **Интеграция**: Telegram-уведомления о результатах обработки и автоматическое управление торрент-клиентом.

## 🛠 Установка

### Способ 1: Docker (Быстрый запуск)
Самый простой способ запустить сервис в изолированном контейнере.
```bash
docker run -d \
  --name media_sorter \
  -p 7887:8080 \
  -v /opt/torrent-media-sorter/config:/app/config \
  -v /mnt/media:/mnt/media \
  -e TZ=Europe/Moscow \
  kornalexandr2/torrent-media-sorter-web:latest
```

### Способ 2: Docker-Compose (Рекомендуется)
Идеально для управления зависимостями и путями.
Пример `docker-compose.yml`:
```yaml
services:
  media-sorter:
    image: kornalexandr2/torrent-media-sorter-web:latest
    container_name: media_sorter
    restart: unless-stopped
    ports:
      - "7887:8080" # Внешний порт : Внутренний порт
    volumes:
      - ./config:/app/config  # Настройки и база данных
      - /mnt/media:/mnt/media # Доступ к вашей медиатеке
    environment:
      - TZ=Europe/Moscow
      - PUID=1000
      - PGID=1000
```
Запуск: `docker-compose up -d`

### Способ 3: В качестве системной службы (Linux / Systemd)
Для установки напрямую на хост-систему (Ubuntu/Debian/CentOS).
```bash
mkdir -p /opt/torrent-media-sorter-web && cd /opt/torrent-media-sorter-web
curl -sSL https://raw.githubusercontent.com/kornalexandr2/Torrent-Media-Sorter-Web/main/install_service.sh | bash
```
Скрипт автоматически создаст виртуальное окружение Python, установит зависимости и зарегистрирует службу `torrent-media-sorter-web.service`.

## ⚙️ Настройка и логика

### Режимы сканирования
При нажатии кнопки **🔄 Сканировать** доступно два режима:
1. **Полная обработка**: Поиск новых файлов -> Распознавание через API -> Переименование и перенос.
2. **Только прочитать папку**: Система только добавит новые файлы в список со статусом **PENDING**, позволяя вам позже вручную исправить сопоставление (Fix Match).

### Каскадный поиск (API)
Сервис опрашивает источники по цепочке: **Kinopoisk -> TMDB -> TVDB**. Если данные не найдены в первом, запрос уходит к следующему. Приоритет можно изменить в настройках.
